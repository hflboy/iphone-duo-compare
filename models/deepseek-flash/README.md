# iPhone Duo · Teardown Lab(DeepSeek-V4.1-Flash 对照组)

用 **Three.js + 原生 HTML/CSS/JS** 实现的 iPhone Duo 交互式 3D 拆解可视化。
整机 25 个部件全部由代码程序化生成:没有外部模型、没有图片贴图、没有构建工具。

## 快速开始

**方式一:直接打开**

双击 `index.html`。首次打开需要联网加载 Three.js:优先读取本地
`js/lib/three.min.js`,不存在时依次尝试 jsDelivr → unpkg → cdnjs → BootCDN → 奇安信五个 CDN;
若希望完全离线,把 r128 版 `three.min.js` 放到 `js/lib/three.min.js` 即可,加载器会优先使用它。

**方式二:本地服务器(推荐,避免 file:// 的剪贴板限制)**

```bash
cd models/deepseek-flash
python -m http.server 8080
# 打开 http://localhost:8080
```

建议使用 Chrome / Edge / Firefox / Safari 的现代版本,需支持 WebGL 与 Pointer Events。

## 技术实现

### 1. 程序化几何
- 圆角矩形轮廓用 `Shape + quadraticCurveTo` 生成,`ExtrudeGeometry` 加倒角构成中框、背板、电池、相机岛等所有壳体。
- 中框是带圆角孔的挤出框体 + 内部中板;相机镜头由圆柱、圆环、圆形玻璃分层嵌套。
- 所有尺寸在 `phone.js` 顶部集中定义,便于调整比例。

### 2. 程序化贴图(零图片)
`textures.js` 用 Canvas 2D 实时绘制:
- 内屏壁纸(极光、光带、同心弧、星点、9:41 锁屏层,沿中线切给左右两半);
- 6.2″ 外屏常亮界面(时间、日期、组件卡片);
- 2962 / 1921 mAh 电池标签(电压、Wh、条码、维修提示);
- 主板 PCB 走线/焊盘/丝印、A20 与 C2 芯片丝印、扬声器网孔、镜头玻璃;
- 钛金属拉丝与磨砂玻璃的粗糙度图。

### 3. 自研轨道控制器
不引入 `OrbitControls`,统一用 Pointer Events 处理鼠标与触摸:
- 球坐标 + 指数阻尼;自动旋转;`focusOn()` 平滑飞行到部件;
- 单指旋转、双指捏合缩放 + 平移;右键/中键平移;
- 按下到抬起的位移 < 7px 且 < 500ms 判定为点击,避免拖拽误触。

### 4. 拆解编排
- 每个部件有独立的 `start` 时间窗(按装配层级错峰)与拆解方向/距离;
- 全局进度 0→1 用 `requestAnimationFrame` 阻尼跟随;滑杆可直接 scrub;
- 左右半机额外向外分离 1.35 单位,露出中央铰链;
- 单独选中部件时叠加 0.95 单位的“抽出”位移,取消选中后回位。

### 5. 折叠机构
右半机挂在 `foldPivot` 下绕 Y 轴旋转 -177.3°,并在折叠过程中沿 Z 补一个厚度偏移,
让两块屏幕面对面、机身叠成两倍厚度,同时把整机重新居中。折叠态下拆解自动归零。

### 6. 视觉与后期
- 深色渐变天穹 + 程序化地面网格 + 星尘 + 地面光环;
- 程序化 “HDR 灯房” 经 `PMREMGenerator.fromScene` 烘成环境贴图,提供钛金属/玻璃反射;
- 自研泛光:亮部阈值提取 → 半分辨率两级可分离高斯模糊 → 场景直出 + 泛光加性叠加(暗角/扫描线由页面 CSS 覆盖层承担);
- 选中部件:自发光脉冲 + `EdgesGeometry` 加性描边 + 跟随点光,三个通道同时高亮。

### 7. 工程细节
- 多 CDN 兜底加载(含本地 `js/lib/three.min.js` 优先),加载失败给出明确提示;
- 材质按部件克隆,保证高亮互不串色;
- 清屏、纹理各向异性、DPR 上限、移动端面板折叠;
- 拆解清单导出为 JSON,可复制/下载。

## 已知限制

1. **首次打开需要联网**取 Three.js;离线需手动放入 `js/lib/three.min.js`。
2. 几何为**视觉近似**,不是 CAD 级尺寸;铰链内部凸轮、排线走向做了简化。
3. 折叠角保留 2.7° 以避免屏幕完全贴合时穿模;折叠偏移是视觉补偿,不是真实四连杆运动学。
4. 后期只有 bloom + CSS 暗角/扫描线,没有 SSAO/景深/真实阴影,以换取移动端帧率。
5. 屏幕为单张平面 + 圆角遮罩,折痕用中缝与暗线暗示,未做真实柔性弯折网格。
